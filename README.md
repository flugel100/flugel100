### What I work on

**Jagoan Medis** — a medical-themed crossword for Android and web from a single
Flutter codebase. Fully bilingual: puzzles are generated separately per language,
because crosswords cannot be translated — intersections demand identical letters
and word length locks the grid. 139 automated tests. Pre-release.
[Play it in the browser →](https://app.flugel.my.id/en/demo/jagoan-medis/)

**Hermod** — a terminal and SSH client for Android, so a server can be driven
entirely from a phone without reaching for a laptop. Rust core, Jetpack Compose
interface. In development.

**Kalkulator Nakes** — offline-first clinical calculators for healthcare workers
in the field, because signal is the first thing to disappear when it matters.

**Dex Bot** — a 24/7 decentralised-exchange token screener that assesses
technical risk and deliberately never promises profit. Verified with mutation
testing: a filter that can never fail is a filter that does nothing.

### How I work

Read the existing code before proposing anything — guessing costs more than
reading. Write down what will *not* be built, so nothing surprises anyone
halfway. Ship in stages that can be tried early. Test, measure, and say plainly
when something can't be verified yet.

I'd rather finish one thing properly than start ten half-heartedly.
